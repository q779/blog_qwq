随笔2 20261023

标题是随笔2，也就是本日的第二篇随笔，当然这不重要。

感慨一下，以前上的某个三流 C++ 兴趣班，教过我们怎么用 Github ，我就是那个时候创建的 Github 账号，

虽然我已经忘记怎么给公共仓库提交内容了，但是这暂时不重要，在我的账号页面上可以看到那个仓库。

距今已经 7 年了，可以看到下面这个贡献者名单（头像最好看的显然是本人，第五个）

可能那是我第一次喜欢上算法的美妙之处，而且当时其他人全在摸鱼，我算唯一在听课的人，也不是很认真。

虽然学了半天就没学明白多少东西，但是这倒不是大问题，至少我感受过了为自己的兴趣而努力的感觉。

现在过这么久再回去看，好像他们都不活跃了，大概最后都没选这条路吧，我不信学计算机会不搞 Github 的

至于那个用真人头像的，我不记得是不是老师本人了，有点像又不太像，不过好像也很久没有活跃了……

让我想起我高一时候的 OI 社团，整个社团就我一个是正儿八经的 OIer，老师甚至不会用 C++ 生成随机数。

看着这个贡献名单的默认头像，再看看那个 7 年没有动静的仓库……

我只觉得令人唏嘘，同时也觉得我比他们在这条路上走得更远、还在一直走是一种理所当然的事。
