随笔4 20261029

写这篇的灵感是来源于知乎上的一个问题：个人博客为什么难以长期持续更新？

个人博客这个话题好像比较小众，点赞的也不多，我找到的下面这个回答看着倒是挺有意思的。

还有一个类似问题的回答

各位如果关注我的博客主站和分站的话（我估计也没几个人吧），应该会发现我这个人非常能写

主站特别能写主要是写的题解，不过最近一直在忙着做别的事，迟迟没写题，那我肯定不会滥竽充数。

而且建了分站以后，我就有了一个非常方便内容管理的小站，而且可以基本上自由地谈论各种各样的内容。

为什么我会一直愿意更新博客呢？我之前有写过，因为我有自闭症，我的脑子里每天都能自发地蹦出无数个话题。

我每天一醒来，直到晚上为止，除非我犯困了或者专注在学习什么东西，否则我的大脑几乎从来不会停下来思考。

我没什么朋友，其中很大的一点原因就是平时我和别人聊天的话题。我对今天吃什么今天什么天气这类话题毫无兴趣。

我和别人聊天通常是这样的话题，比如：人为什么要结婚？人为什么要生娃？人为什么要活着？（只是举个例子）

这类问题很显然都是不太容易回答的，而且很多这样的问题别人都没怎么去想过，况且很多问题都没有唯一答案。

其次，我的好奇心简直是无穷无尽的，自从 AI 大模型出现以后，我终于可以随时随地问各种各样的问题了。

我以前高中学生物学化学的时候，问问题问的朋友（甚至老师）都懵了，说你怎么会有这么多的问题。

除此以外，自从我进入闭关修炼的状态以后，我的话题几乎全是我自己，我也不太好形容这种感觉。

就是我自己讲着讲着就发现，自己好像一直在讲自己是如何想的如何做的，而且其实我不太在意有没有回应。

对我来说，只要我的文章、我的讨论在理论上是有人能看到的，我就觉得足够了，人多了反而会觉得不舒服。

你说我是为了记录自己的想法才写博客的吗？不是。是因为我不说出来写出来，大脑就没法进行高效的思考。

这应该是我自闭症的缺陷，我的工作记忆是比较差的，同时不能记住太多东西，写出来就不会忘记了。

对我来说，如果冒出来一个问题不知道答案，就会非常想去知道为什么，知道就会让我觉得很开心，反之就很难受。

好吧，叽里咕噜，其实就是我的所有对话、聊天、讨论本质上就是找一个人当外接存储器和分享对象。

我后来知道这就是所谓的演讲式对话，是阿斯伯格综合征（现在统一叫自闭症谱系障碍）的一个显著特征

我的分享只是顺便的事，有不少文章觉得不适合放出来我写完就直接存起来了，过一段时间很可能就直接删掉了

言归正传，我写文章的好处是我的思维速度比我的讲话速度要快得多，和我的打字速度稍微快一点点。

我如果和我妈聊天，经常可以连续讲几个小时不停，还不重样的那种，有时候说太多喉咙都有点哑了。

打字就会轻松很多，不过就像我说的，没什么朋友，发消息一般不会，发多了像是骚扰别人，我就来写文章了。

最前面那个回答说，“如果你把个人博客当作打造个人 IP 的工具，那么大概率是很难坚持下去的。”

他搬出的理由是，文章阅读量通常很小，而且很少会有人搭理你评论你，意思就是没有正反馈什么的

那我是怎么样的呢？我的表达通常是思考和整理，而我只要思考就会感觉非常开心，得出结论更是开心了。

另外，没有评论区和阅读量反而让我觉得安心，我很担心有太多人看我的东西，或者对我的东西指指点点。

因为很多人都很笨啊，聪明人只是少数的，和笨蛋讲了半天对面听不懂或者固执的很，纯纯浪费时间。

如果真的有人看到这里的话，那么实话说我也不能没有什么感谢的意愿，我只是觉得哥们你也不简单、有点意思。

打造个人 IP 什么的，感觉无意间确实在打造。不过我自己觉得自己就是非常好的一个人啊，自信的不得了。

自信过头了我会看看比我厉害的人，自信不够了我会看看世上有这么多笨蛋呢，也说不上是一个自恋狂。

我觉得我的博客风格太棒了，我觉得我的审美太棒了，我觉得我在思考东西这方面太有实力了。

不过我也知道我和我认识的数学高手、计算机高手差距确实很大，他们的数学思维确实是比我好，这我知道，

但你也不能否认的是他们许多关于社会的观点也未必比我想得透彻，在心理学方面也未必比我有天赋。

而且就算都比我厉害，我也不会觉得有什么，我从来没觉得自己是世界上最厉害的人，我只是觉得自己特别厉害

至于赚钱啊维护成本啊，我放 github 上就只有主站域名有一丢丢费用，而且主要是用来宣传我自己的，几乎零成本。

而且我本来就是学计算机的，能顺便学习学习各种开发，还缓解了自己疑似过度的分享欲，这不是一举 N 得吗？

对啊，而且我还会写各种小科普文章（其实是我自己的杂七杂八笔记），打打字 COPYCOPY 也不花多少力气。

就写到这吧，这个故事告诉我们，每个奇怪的现象背后，一定有着更奇怪的、或是由无数巧合组成的复杂原理。


不过各位，虽然我叽里咕噜的讲东西确实很能写，但是让我写语文作文这种东西我那叫一个头疼啊。

还好我现在慢慢在开发自己的感性、培养自己对语文的兴趣，也许有朝一日这就不会是一个难题了。

然后我出门被车撞似了，全剧终。不过我相信这么写故事的作者，肯定会被读者骂到死。

不过还是别一天到晚想这些不好的事，这些想法应该是作为完美主义者在现实中受挫后留下的某种 PTSD 。
