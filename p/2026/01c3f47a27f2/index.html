草台班子这一块

众所周知，用 Hexo 写博客，需要在文章前面加上一段 hexo-front-matter 来配置文章

我才懒得手打呢，于是我一直开着一个叫 ---.txt 的文档，里面有经常用到的杂七杂八东西

比如下面这种

---
title: ""
tags: [""]
categories: "随笔"
mathjax: true
---

没错，就是上面这段，直到我建设这个站的时候出 bug 了才发现

好家伙，我一直写的都是 tag 而不是 tags ，而且之前居然一点都没出问题？

经过我的研究和搜索，我在 Hexo 的代码里找到了下面的段落

if (data.category && !data.categories) {
  data.categories = data.category;
  data.category = undefined;
}

if (data.tag && !data.tags) {
  data.tags = data.tag;
  data.tag = undefined;
}

居然还有贴心的防蠢设计，这能绷住？

就，到目前为止写的一千多篇文章，居然一直保留着这么个低级错误，草台班子就是说。
